Using cheats on PS5

On PlayStation 5, open the phone, hold L1 + R1 and press the arrows on the D-Pad. Keep both buttons held for the whole sequence. If you make a mistake, release and start again. The DualSense gives a small vibration when the cheat is accepted.

Trophies are disabled for the session as soon as a cheat is active. If you are hunting the Platinum, keep a clean save and load a separate one for cheating.
